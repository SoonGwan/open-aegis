# ARTEX 기능 비교 및 구현 범위

ARTEX의 2026-10-04 공개 README 구성을 참고했습니다.
기준 커밋과 원본 기능 구조, 미구현 기능의 완료 조건은 [ARTEX 검토](ARTEX-REVIEW.md)에
정리했습니다. 원본의 설명을 실제 실행 검증 결과로 취급하지 않습니다.

Open Aegis는 독립 구현입니다. 아래의 ‘구현’은 해당 기능의 현재 범위를
뜻하며 ARTEX와 동등한 구현이나 검증 범위를 뜻하지 않습니다.

## 다음 개발 우선순위

1. 상세 내부 위치와 나머지 모달 URL 상태, 엔진 내부 조회 크기·보존 주기·장시간 운영 부하 검증. 주요 발견의 관련 ID 요약, 관찰을 포함한 목록과 MCP 페이지는 구현.
2. API 권한 정책의 전체 모바일·최대 입력·접근성 사용자 여정 검수. 전용 폼·JSON 편집, 제한된 기대 응답 스키마·소유권 필드 비교·승인 정책 내보내기·화면 다운로드와 재현 CLI는 구현.
3. 실행 제한·큐 지표·조치 이력의 운영 부하·장시간 검증. 기능 동작, 실제 관계 그래프와 커버리지는 구현.
4. 팀·테넌트 분리, 감사 체크포인트 외부 보관 자동화·상시 상태, PostgreSQL 저장소. 역할별 권한, 로컬 감사 연결 검증과 관리자 수동 검사 UI는 구현.
5. 검토 가능한 확장 도구 인터페이스와 MCP 클라이언트 연동.
6. 서명된 릴리스, 데이터 마이그레이션, 백업 복구·업데이트 자동화.

새 기능은 동작 검증과 범위 통제를 갖춘 뒤 구현 상태를 갱신합니다.
