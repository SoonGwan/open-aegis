# Worker 관찰을 계획 우선순위에 반영

후속·교체·재실행 계획은 생성 당시 확인한 Worker 관찰을
worker_observation_context에 저장한다. 규칙·AI Planner가 이 맥락으로 승인된
도구의 순서를 정한다. 관찰 URL을 방문하는 도구 실행 입력, 취약점 판정, 자유
문장의 목표 분해와 별개이며 이 단계만으로 전체 Worker 관찰 소비를 완료하지 않는다.

## 입력의 출처

검증된 최대32개 계획 이력의 승인된 작업에서 SQL 페이지를 읽는다. 관찰의 ID와
저장 키, 작업/자산/도구 버전/패키지 지문, 승인 범위 메타데이터가 일치해야 한다.
해당 Worker의 endpoint_inventory 커버리지가 완료이고 같은 자산 revision이어야
한다. 현재 자산도 활성·권한 확인 상태이며 관찰 당시 URL/revision과 일치해야 한다.
불일치·미완료·오래된 범위·쿼리/fragment/사용자 인증 값이 든 URL은 사용하지 않는다.
심하게 손상된 목록 형식은409로 계획을 거절한다.

최신 회차부터 최대100개 관찰을 확인한다. 전체·확인·포함·제외·표본 밖 개수를
함께 저장한다. 표본 밖 자료를 검증했다고 표시하지 않는다. 맥락 JSON UTF-8
64KiB를 초과하면 거절하며 필드 중간을 자르지 않는다. 저장된 항목에는 관찰 ID,
출처 작업/자산, URL/범위 URL/revision, 패키지 지문과 경로 유형이 있다. 지문은
정규 JSON SHA256으로 내부 일관성 검사이며 DB 관리자에 대한 서명이 아니다.

## 해석과 도구 순서

URL의 디코딩된 경로 구간을 다음 유형으로 분류한다.

- 세션: login/logout/signin/signout/session/auth/oauth → 쿠키·전송 보안 우선.
- 관리: admin/manage/management/settings → API 권한 검증 우선.
- API: api/graphql/rest → CORS·API 권한 검증 우선.
- 나머지: 별도 우선순위 없음.

여러 유형이 겹치면 세션·관리·API 순으로 분류한다. 이는 경로 이름의 추정이며
접근 가능 여부·실제 API·보호 데이터 존재·취약점·소유권의 증거가 아니다.
사람이 공유 할 일에 요청한 도구를 기존 선택 순서대로 먼저 두고, 나머지 승인된
도구 중 관찰 유형과 관련된 도구를 앞에 둔다. 도구 선택·자산·권한 규칙을 추가하거나
검증을 생략하지 않는다. API 권한 검증도 기존 등록된 규칙만 실행한다.

AI에는 관찰의 id/task_id/asset_id/scope_revision/category, 집계 개수와 맥락 지문을
보낸다. 관찰 URL·경로 원문·응답 원문·인증 값은 이 입력에서 보내지 않는다.
기존 운영자 목표/자산 이름/공유 할 일 입력은 별도 계약을 유지한다. 경로 유형은
신뢰할 수 없는 참고 데이터임을 알리며 응답은 승인된 도구의 정확한 순열이어야 한다.
사용량 기록에는 지문과 관찰 ID 참조를 남긴다. 실제 상용 제공자 검수는 남아 있다.

## 저장과 검토

후속 제안 지문에 맥락을 포함한다. 조회 이후 포함 항목/유형/범위/집계가 바뀌면
기존 제안으로 반영할 수 없다. 최종 쓰기 트랜잭션에서도 다시 계산한다. 이미 만든
계획은 이후 원본 관찰 변경으로 바뀌지 않으며 재계획/재실행은 현재 맥락을 다시
저장한다. 규칙/AI 실행 전에는 저장된 형식·분류·ID·지문을 검사한다.

제안 검토와 작업 상세에서 생성 당시 링크·유형·범위 버전·출처 작업과 집계/제외를
펼쳐 읽는다. URL은 코드 텍스트이며 방문 버튼이 아니다. 현재 원본과 다를 수 있다.
자동 이벤트 처리기는 같은 맥락을 제안에 저장한다. 관찰 저장 자체는 일반 감사
이벤트를 항상 생성하지 않으므로 실행 종료/다른 변경 이벤트가 처리 시점이 되며,
DB 직접 변경만을 자동 감지한다고 보장하지 않는다.

명시적으로 선택한 관찰 URL의 새 승인 응답 설정 검사는
[OBSERVATION-EXECUTION.md](OBSERVATION-EXECUTION.md)에 정리했다. 의미적 목표 분해·관찰 해석,
외부 도구 격리/원격 MCP, 장시간 처리 부하·보존 정책과 전체 모바일/SR는 남아 있다.
