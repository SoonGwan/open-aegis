# 관찰 검사 미완료 결과의 자동 공유 할 일

종료된 승인 관찰 응답 작업을 이벤트 계획 처리기가 검토할 때, 검증된 다음
계획의 실패·누락·오래된 결과 조합을 공유 할 일로 기록한다. HTML이나 자연어의
의미를 추론하지 않는다. 원본은 관찰 ID와 검사 ID이며 URL 원문·응답·인증 값을
할 일에 복사하지 않는다. 검사 실패는 취약점이나 목표 달성 판정이 아니다.

같은 계획 가족과 같은 미완료 조합은 같은 ID를 사용한다. 반복 이벤트와 재시작은
중복을 만들지 않는다. 사람이 수정한 제목·설명·상태·담당자·완료 사유를 보존하며
완료·취소 기록을 다시 열지 않는다. 미완료 조합이 달라지면 별도 기록을 남긴다.
최초 출처 작업과 조합·지문의 `automatic_origin`은 유지하며 손상 시 제안 준비를
차단한다. 화면에서 자동 생성 안내와 원본 관찰 검사 작업 버튼을 제공한다.

자동 기록의 `check_ids`는 빈 배열이다. 도구 요청·새 작업·대상 요청·승인을
자동 생성하지 않는다. 사람이 이후 도구를 요청하면 기존 공유 할 일 계약과
[관찰 후속 회차](OBSERVATION-ROUNDS.md)의 새 승인 절차를 따른다.

할 일·변경 이력·감사 이벤트·새 맥락을 반영한 제안·처리 위치를 같은 트랜잭션에
저장한다. 저장 실패 시 전부 되돌리고 같은 이벤트를 다시 처리한다. 자동 생성
이전의 제안 지문으로 반영하면 변경된 맥락 때문에 거절한다. 계획 맥락의 100개/
64KiB 한도를 넘으면 기록을 추가하지 않고 `automatic_todo.status=limited`를
표시한다. 기존 기록은 보존하며 한도 안내를 제공한다.

처리 정책 지문에는 자동화 revision을 포함한다. 이전 버전의 처리 위치는 과거
이벤트부터 다시 검토해 미완료 결과를 기록할 수 있다. 안정적인 ID로 중복을
방지하며 재처리도 대상 요청이나 실행 권한을 만들지 않는다.

SQLite·네이티브 PostgreSQL에서 생성·반복·사람 결정 보존·원자 롤백·한도·이전
제안 거절·참조 손상·이전 처리 위치 재개를 검증한다. 자동 의미 해석·자연어 기대
근거 판정·전체 모바일/스크린리더·장시간 및 혼합 버전 운영은 별도 미완료 항목이다.
