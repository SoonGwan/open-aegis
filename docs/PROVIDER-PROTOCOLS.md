# 제공자 API 형식

고정 수신처의 `protocol`을 생략하거나 `openai`로 지정하면 기존 OpenAI 호환
동작과 검토 지문을 유지한다. `anthropic`은 직접 Claude API의 텍스트 요청 형식이다.
설치자가 `AEGIS_MODEL_DESTINATIONS`에서 명시하며 모델 이름/호스트로 추측하지 않는다.
지원하지 않는 값은 서버 시작 때 거절한다. 클라우드 플랫폼별 IAM 어댑터는 별도다.

```json
[{"id":"claude","name":"Claude API","base_env":"CLAUDE_MODEL_BASE","key_env":"CLAUDE_MODEL_KEY","protocol":"anthropic"}]
```

`CLAUDE_MODEL_BASE=https://api.anthropic.com/v1`과 키는 환경변수로 설정한다.
주소·키를 화면에서 받지 않는다. 추가 수신처의 실험용 HTTP는 기존 계약대로
명시적 `lab_http`와 리터럴 loopback만 가능하다. 프로토콜이 검토 지문에 포함되어
변경 시 프로필과 용도/작업 선택을 다시 검토해야 한다. 기존 기본 형식의 저장 지문은
변경하지 않는다. 호출/확인 영수증의 당시 스냅샷에는 새 형식을 보존한다.

## 요청과 응답

[공식 메시지 API](https://platform.claude.com/docs/en/api/messages/create)의
`/messages`, 최상위 system 텍스트와 user/assistant 텍스트를 사용한다.
[공식 인증/버전 계약](https://platform.claude.com/docs/en/api/overview)에 따라
`x-api-key`, `anthropic-version: 2023-06-01`을 보내며 OpenAI Bearer 헤더를 함께
보내지 않는다. 이 어댑터는 단일 워크스페이스 키를 사용하며 다른 워크스페이스를
선택하는 헤더를 추가하지 않는다. 자동 재시도·장애 전환·스트리밍은 없다.

계획 순서·자연어 목표 초안·기록 기반 대화는 native 출력 상한4096토큰이다.
명시적 연결 시험은 기존16토큰/고정 메시지만 보낸다. 파일·이미지·도구·skills·
서버 도구·생각/캐시 제어를 요청하지 않는다. 텍스트 블록과 정상 종료만 받아 기존
계획 형식/자산·도구 제한/인용 소속/연결 표식을 다시 검사한다. 거절·도구/생각 블록·
출력 상한 종료·잘못된 JSON은 확인 성공으로 처리하지 않는다. 이는 AI 내용의
사실성이나 목표 달성 검증을 보장하지 않는다.

목표 초안도 출처 작업의 검토한 계획 모델을 포착하고 전송 직전에 다시 검사한다.
기존 목표 초안이 기본 환경변수만 읽어 선택한 프로필을 무시한 문제를 수정한다.
원래 초안 요청 ID의 재확인은 저장된 원래 결과를 읽고 제공자를 다시 호출하지 않는다.
프로필 선택·목표 초안 저장으로 실행을 승인하지 않는다. 후속 작업은 별도 새 승인을
기다리며 모델 고정을 자동 복사하지 않는다.

[공식 모델 목록](https://platform.claude.com/docs/en/api/models/list)은 고정
`GET /models?limit=256` 한 번으로 조회한다. `has_more=false`만 전체 목록으로
받으며 추가 페이지가 있으면 `catalog_incomplete` 실패로 남긴다. 최대256개/1MiB와
시간 제한을 유지하고 다른 페이지/다른 URL을 자동 호출하지 않는다.

DNS/IP 고정, 고정 주소/현재 검토, 작업 실행 소유권, deadline/중지, 응답 크기와
명시적 연결·목록의 인코딩/콘텐츠 타입 검사를 유지한다. 리다이렉트를 따라가지 않는다.
원문 응답·인증 키·전체 수신처 URL은 모델 확인 영수증에 보존하지 않는다.

## 사용량과 호환성

응답의 input/output 카운터를 각각 입력/출력으로 보존하지만 제공자가 보내지 않은
총 카운터를 만들지 않는다. 따라서 정상 native 사용량도 현재 일반 집계에서
`partial`이며 총량과 단일 요율 비용 추정은 판정 불가다. 캐시/서버 도구/기타 요율의
실제 청구를 합산한다고 주장하지 않는다. 당시 설정 가격의 출처와 실청구는 별개다.

이전 프로그램은 `protocol=anthropic` 설치 구성을 읽지 못하고 시작을 거절한다.
기록 보존 목적의 구버전 유지보수는 AI 키/대화를 비활성화하고 native 수신처 항목을
제외한 설정으로 수행해야 한다. 기존 선택을 다른 제공자로 자동 변경하지 않는다.
이전 프로그램의 native 실행 호환성을 제공하지 않는다.

## 검수 상태

실험 작업 공간에서 두 저장소의 실제 소유한 HTTP 제공자로 계획·기록 대화·
연결/목록과 원래 영수증 재확인, 프로토콜 변경의 호출 전 거절, 잘못된 응답/리다이렉트·
불완전 목록 거절을 검수 중이다. 목표 초안의 선택 무시를409로 재현한 뒤 수정본과
기존 SQLite/PostgreSQL 목표 검사를42개 통과했다. 첫 형식/실제 호출 검사55개를
통과했고 확장 관련 native 회귀324개·native 소유권 전용 SQLite2개 건너뜀
(162.45초), Node122개·TypeScript/production build를 통과했다. checkout 밖 독립 설치본은752개 통과·같은 SQLite2개 건너뜀(341.71초)이다.

실제 소유한 브라우저에서는 native 연결/목록의503→새 문서→원래 요청200을
확인하고 추가 제공자 요청 없이 원래 영수증을 유지했다. 불완전 목록의 실패 표시,
기본 환경 키 없이 출처 작업 선택1의 목표 초안과 기록 대화·당시 스냅샷/부분 토큰을

설치본102→101→102와 오프라인 복원도 두 저장소를 통과했다. 실제 native 목표/
대화/연결·목록 영수증과 생성·선택·프롬프트/알림/보관 기록, 명시적 합성 호출 스냅샷을
보존했다. 처음 의도한 native POST6개·목록 GET2개·알림 POST2개 외 전환/재확인/
복원의 추가 요청은 없다. 선택한 행/체크포인트 동일성·복원 세션0개·자원 정리를
