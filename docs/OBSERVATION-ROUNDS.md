# 관찰 URL 응답 검사를 다음 승인 대기 회차로 연결

승인되어 종료된 관찰 응답 작업의 `GET /api/tasks/{id}/next-plan`은 기본 자산
응답 검사와 별도로 다음 관찰 회차를 제안한다. 종료/변경 이벤트의 자동 계획
처리도 같은 제안을 준비한다. 제안 조회와 준비는 대상 요청이나 작업 생성이 아니다.
운영자가 지문을 검토해 POST로 반영하면 새 승인 대기 작업이 생기며 관리자 승인이
있어야 GET 검사를 실행한다. 발견 재검증 작업은 원래 발견에서 새 재검증을 만든다.

## 실행과 증거

원래 선택한 관찰 ID와 검사 목록을 유지하고 실제 실행할 **관찰 ID × 검사**를
`observation_cells` 계약으로 고정한다. 최대10개 URL ×4개 응답 검사, 최대40개
조합이며 중복·범위 밖 ID/검사·원본 회차 불일치·선택 계약 제거는 거절한다. 선택은
도구·URL·범위와 함께 승인 지문에 포함된다. 교체·재실행은 회차와 선택을 유지하며
새 승인을 요구한다.

URL별 실패·취소·누락/손상 결과만 선택한다. 이미 승인한 같은 관찰 회차의 완료
결과는 보존하며, 후속 작업의 생략한 조합으로 덮어쓰지 않는다. 결과를 확인할
URL/검사 조합이 없는 자산은 요청을 보내지 않는다. 같은 URL을 여러 검사에서
선택하면 응답을 재사용한다. 범위·권한·출처 관찰 또는 원래 목표 과제가 변경되면
기존 제안을 거절하고 출처에서 새 선택을 요구한다. 자연어 목표 달성·안전 판정은
수행하지 않으며 기본 자산 응답 완료율에 합산하지 않는다.

## 공유 할 일과 원자 반영

같은 관찰 회차 가족의 활성 공유 할 일이 **기존 선택 검사**를 요청하면 해당
검사를 모든 원래 선택 URL에 제안한다. 완료 검사 반복도 새 승인 대상이다.
원래 선택에 없는 도구 요청은 기존 제안으로 범위를 늘리지 않고 새 관찰 선택을
요구한다. 원래 목표 과제 참조와 할 일 맥락은 후속 작업에 보존한다.

선택·URL별 결과·현재 자산·도구·실행 정책·공유 할 일·이력을 지문으로 검토하고
최종 쓰기에서 다시 계산한다. 변경 시 원본 연결/새 작업/커버리지/감사 쓰기를
일부 남기지 않는다. 같은 지문의 재반영은 연결된 기존 회차를 반환하며 손상된
이력은 거절한다. 기존8회차와32개 연결 이력 한도를 유지한다.

자동 관찰 의미 해석·공유 할 일 자동 생성·자연어 기대 근거 충족 판정·실제 모바일/
스크린리더 전체 여정과 혼합 버전 운영 검수는 아직 미완료다.
