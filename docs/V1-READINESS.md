# Open Aegis v1 출시 기준

목표는 ARTEX를 참고한 독립 오픈소스 보안 검증 서비스를 기능·디자인·운영 모두
실제 배포할 수 있는 수준으로 완성하는 것이다. 체크박스가 없는 항목은 미완료다.
0.1 기능을 갖췄다는 이유로 v1을 선언하지 않는다.

## 디자인과 사용자 경험

- [x] Wanted Montage semantic 색상 출처·값·의미 정리, 중앙 토큰 사용.
- [x] Neo-brutalism: 명확한 테두리, 평면 색, 단단한 그림자, 눌림 상태.
- [ ] 전체 화면의 desktop/mobile 시각 검수와 회귀 기록.
  - 14개 주요 화면의 실제 320/390px 문서 너비에서 가로 넘침을 측정. 보고서·작업/발견 상세 일부 스크린샷 검수와 보고서 버튼 줄바꿈 개선.
    전체 상태·스크롤/터치·실제 모바일 브라우저·desktop 회귀 검수는 남아 있음.
- [ ] 주요 사용자 여정의 키보드·스크린리더·포커스·대비 확인.
  - 공용 모달의 주기 갱신 포커스 유지, summary·스크롤 영역 순환, 비활성/음수 Tab 제외, Escape 복원과 이름·설명 연결을 브라우저에서 검수.
    실제 스크린리더와 전체 여정 검수는 남아 있음.
- [ ] 빈 결과, 오류, 저장 중, 복구 상황의 일관된 동작 검증.
  - 보고서 다운로드의 진행·중단·한도 초과 대기·수동 재시도를 실제 화면에서 검수.
    HTML/빈 응답/전송 실패 거절은 단위 검증. 대용량 브라우저 자원과 전체 화면 복구 검수는 남아 있음.
- [ ] URL에 탐색 상태 보존, 검색·필터·페이지네이션.
  - 9개 주요 목록과 그래프 북마크 구현. 주요 목록의 새 문서 복원·이전/다음 이력·오류 복구 검수.
    노트 마지막 페이지 삭제 후 위치 보정, 예약 필터·중지 후 위치 유지 검수.
    관찰의 전체 조회·출처 검색·새 탭 복원 검수. 작업·발견 ID의 상세 URL, 닫기·이전/다음 복원·오류 재시도 구현·검수.
    발견의 증거·재검증 목록 펼침·검색·페이지 북마크와 새 탭·이전/다음 복원 검수.
    작업 기록·대화·조치 이력 위치·개별 원본 펼침/스크롤·나머지 모달 URL, 전체 모바일 회귀는 남아 있음.

## 자산·실행·발견

- [x] 자산 수정·보관·복원과 승인 범위 revision 검증.
- [x] 보관 시 예약 중지, 증거 이력 유지, 재개 시 명시적 선택.
- [ ] 대량 자산·작업·증거 목록의 SQL 필터·페이지네이션 및 UI.
  - 자산·작업·발견·트래픽 및 승인·보고서·노트·예약·관찰 화면은 SQL 검색과 25개 페이지 적용.
    계획 생성의 자산 선택은 페이지 간 선택 유지. 발견별 증거·재검증 이력은 SQL 검색·25개 페이지·출처 검증 적용.
    MCP 목록·증거·재검증·이벤트 페이지와 관련 ID SQL 요약은 구현([MCP.md](MCP.md)).
    주요 HTTP 발견 조회·저장 응답의 관련 ID 요약도 구현. 작업 상세의 발견·이벤트도
    최신 25개 요약·전용 SQL 페이지·독립 검색 및 발견 상세 이동을 구현·검수.
    작업 대화도 SQL 검색·25개 페이지·전송 후 최신 복귀와 질문·답변 원자적 저장을 구현.
    전송 ID별 서버 중복 방지와 동일 질문의 화면 재시도도 구현·검수.
    같은 탭의 새 문서·상세 재진입에서 미확인 질문 복원도 구현·검수. 기기 간 복원과 전송 전 초안 보존은 없음.
    보고서는 같은 읽기 스냅샷에서 전체 결과를 스트리밍하며 중단 시 연결 종료를 검증([REPORTS.md](REPORTS.md)).
    내보내기 동시 실행·시간 제한과 거절·완료·중단·시간 초과 지표도 구현·검증.
    서비스 코드의 Store.all 조회를 제거하고 재시작 미완료 작업 100개 배치·자산 SQL 존재 검사·예약 ID 조회를 구현·검증.
    단일 payload·연관 ID 배열/예약 중지 감사 크기와 상세 내부 위치·나머지 모달 URL 상태 보존,
    장시간 부하 검증은 아직 남아 있다.
- [ ] 기대 응답 스키마·소유권 등을 포함한 API 정책 모델과 재현 내보내기.
  - GET 규칙의 제한된 JSON Schema 2020-12 응답 계약·JSON Pointer 소유권 문자열 비교·승인 스냅샷·민감 응답 비저장 구현.
    실제 loopback HTTP의 계약 일치·불일치·소유권·거절·잘림·판정 불가 검증. 승인 정책 내보내기·별도 실행 CLI·요청 전 범위 검사·명시 실행·제한 축소·민감 값 비출력 검증.
    작업 상세 다운로드·조건 안내·503 오류/수동 재시도·320/390px 문서 가로 넘침 검수.
    전용 폼·JSON 편집, 추가/삭제 포커스, 저장·재열기·오류 입력 보존과 단독 컴포넌트의 320/390px 너비 검수.
    전체 모바일 등록·최대 입력·보조 기술 여정은 남아 있음([API-POLICY.md](API-POLICY.md)).
- [x] 연결 가능한 실제 관계 엣지와 선택·필터를 가진 그래프.
  - [GRAPH.md](GRAPH.md): 자산·작업 범위, 증거 출처 확인, SQL 페이지, 노드 선택·북마크·키보드 이동·모바일 목록 검증.
- [x] 대상별 속도 제한, 실행 timeout, 작업 큐 운영 지표 및 재시도.
  - [RUNTIME.md](RUNTIME.md): origin 공유 제한, DNS·느린 응답·중지, 대기열 만료, 새 승인 재실행, 종료 검증과 보장 한계.
- [x] 실패·건너뜀을 포함한 검증 분모와 최신 커버리지.
  - [COVERAGE.md](COVERAGE.md): 승인 시각·현재 revision, 중지/재시작, 이전 기록 누락, 2,000개 자산 집계 검증.
- [x] 발견 사항 담당자, 수용 사유, 변경 이력, 안정적인 상태 보존.
  - [TRIAGE.md](TRIAGE.md): 조치 버전 충돌, 재검증 결과와 결정 분리, 반복 관찰 상태 보존.
