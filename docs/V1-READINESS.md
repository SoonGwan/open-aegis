# Open Aegis v1 출시 기준

목표는 ARTEX를 참고한 독립 오픈소스 보안 검증 서비스를 기능·디자인·운영 모두
실제 배포할 수 있는 수준으로 완성하는 것이다. 체크박스가 없는 항목은 미완료다.
0.1 기능을 갖췄다는 이유로 v1을 선언하지 않는다.

## 디자인과 사용자 경험

- [x] Wanted Montage semantic 색상 출처·값·의미 정리, 중앙 토큰 사용.
- [x] Neo-brutalism: 명확한 테두리, 평면 색, 단단한 그림자, 눌림 상태.
- [ ] 전체 화면의 desktop/mobile 시각 검수와 회귀 기록.
- [ ] 주요 사용자 여정의 키보드·스크린리더·포커스·대비 확인.
- [ ] 빈 결과, 오류, 저장 중, 복구 상황의 일관된 동작 검증.
- [ ] URL에 탐색 상태 보존, 검색·필터·페이지네이션.

## 자산·실행·발견

- [x] 자산 수정·보관·복원과 승인 범위 revision 검증.
- [x] 보관 시 예약 중지, 증거 이력 유지, 재개 시 명시적 선택.
- [ ] 대량 자산·작업·증거 목록의 SQL 필터·페이지네이션 및 UI.
  - 자산·작업·발견·트래픽 및 승인·보고서 화면은 SQL 검색과 25개 페이지 적용.
    계획 생성의 자산 선택은 페이지 간 선택 유지. 증거·관찰·노트·예약의 전체 조회
    정리, URL 상태 보존 및 장시간 부하 검증은 아직 남아 있다.
- [ ] 기대 응답 스키마·소유권 등을 포함한 API 정책 모델과 재현 내보내기.
- [ ] 연결 가능한 실제 관계 엣지와 선택·필터를 가진 그래프.
- [ ] 대상별 속도 제한, 실행 timeout, 작업 큐 운영 지표 및 재시도.
- [ ] 실패·건너뜀을 포함한 검증 분모와 최신 커버리지.
- [ ] 발견 사항 담당자, 수용 사유, 변경 이력, 안정적인 상태 보존.

## 협업·연동

- [x] 사용자·역할(admin/operator/viewer)과 서버 측 권한 검사.
- [ ] PostgreSQL 저장소와 SQLite 마이그레이션, 지원 구성의 실제 검증.
- [ ] 검토된 확장 도구 계약과 등록·실행·결과 검증.
- [ ] 제한된 원격 MCP 클라이언트와 스코프·권한 검증.
- [ ] ScopeSentry 가져오기·동기화, 원본/중복/삭제 정책.
- [ ] 기록 기반 AI 대화와 개입의 승인 상태 관리, 토큰 사용량.

## 운영·릴리스

- [x] 데이터 스키마 버전과 마이그레이션 테스트.
- [x] SQLite 백업 검증·복구 도구, 세션 무효화, 복구 리허설.
- [ ] PostgreSQL 백업·복구 경로와 검증.
- [ ] 감사 로그 연결 해시·검증·외부 체크포인트(변조 탐지 한계 명시).
- [ ] 보존 정책(증거 참조 보장), 자원 사용량·보안 운영 지표.
- [ ] 실제 컨테이너 build/start/health/shutdown 검증.
- [ ] 업데이트 전 백업, 호환성 검사, 서명된 릴리스·롤백 절차.
- [ ] 실제 TLS fixture·LLM 호환 fixture·부하·재시작·장애 검증.
- [ ] 설치 가이드, threat model, 보안 신고, 릴리스 아티팩트, 공개 저장소.

임의 명령·자율 침입·데이터 탈취 기능은 서비스의 검증 도구 계약에 포함하지 않는다.
현재 구현과 ARTEX의 차이는 [FEATURES.md](FEATURES.md)에 별도로 유지한다.
외부 계정/배포 목적지가 필요한 공개 작업은 해당 환경이 준비되어야 검증할 수 있다.
