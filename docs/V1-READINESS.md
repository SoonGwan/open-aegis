# Open Aegis v1 출시 기준

목표는 ARTEX를 참고한 독립 오픈소스 보안 검증 서비스를 기능·디자인·운영 모두
실제 배포할 수 있는 수준으로 완성하는 것이다. 체크박스가 없는 항목은 미완료다.
0.1 기능을 갖췄다는 이유로 v1을 선언하지 않는다.

## 디자인과 사용자 경험

- [x] Wanted Montage semantic 색상 출처·값·의미 정리, 중앙 토큰 사용.
- [x] Neo-brutalism: 명확한 테두리, 평면 색, 단단한 그림자, 눌림 상태.
- [ ] 전체 화면의 desktop/mobile 시각 검수와 회귀 기록.
  - 14개 주요 화면의 실제 320/390px 문서 너비에서 가로 넘침을 측정. 보고서·작업/발견 상세 일부 스크린샷 검수와 보고서 버튼 줄바꿈 개선.
    전체 상태·스크롤/터치·실제 모바일 브라우저·desktop 회귀 검수는 남아 있음.
- [ ] 주요 사용자 여정의 키보드·스크린리더·포커스·대비 확인.
  - 정책 스키마/JSON 오류의 입력·도움말 연결과 상태 표시를 보강.
    잘못된 제출의 입력 포커스/차단, 전환 경고 연결, 수정 후 키보드 제출을 합성 폼에서 검수.
    오류 상태의 320/390/768px 실제 문서 가로 넘침을 측정. 실제 스크린리더 검수는 남아 있음.
  - 인증 후 첫 Tab의 본문 건너뛰기·현재 제목 포커스·URL 보존·본문 Tab 이어짐·모달 배경 inert를 desktop에서 검수.
  - 공용 모달의 주기 갱신 포커스 유지, summary·스크롤 영역 순환, 비활성/음수 Tab 제외, Escape 복원과 이름·설명 연결을 브라우저에서 검수.
  - 공용 모달의 마지막 네이티브 라디오 그룹에서 Tab 이탈을 재현·수정.
    선택/미선택·방향키 변경·서로 다른 폼의 같은 이름 그룹·주기 갱신/기존 스크롤 영역을 desktop에서 검수.
    긴 라벨의 실제 320/390/768px 문서 가로 넘침과 세로 스크롤 영역을 확인.
    실제 스크린리더와 전체 여정·모바일 터치/줌 검수는 남아 있음.
- [ ] 빈 결과, 오류, 저장 중, 복구 상황의 일관된 동작 검증.
  - 로그인/최초 설정의 동시 제출 검사·인증 입력 잠금·진행 상태·폼 오류 설명 연결을 보강.
    실제 빌드된 앱에서 수정 전 연속 제출의 HTTP 요청 2개를 재현하고, 수정 후 요청 1개,
    실제 401 뒤 잠금 해제/정상 재시도와 빈 워크스페이스의 최초 관리자 설정을 검수.
    전체 모바일·키보드·보조 기술·원격 설치 토큰 오류 여정은 남아 있음.
  - 이전 API의 늦은 401이 새 로그인을 만료시키는 순서를 재현·수정.
    현재 401/중복 만료·실패한 로그인·본문 지연/중단을 단위 검증하고 실제 API
    모듈/보고서 컴포넌트의 합성 브라우저 이벤트를 검수. 실제 인증 경합·다른 탭 검수는 남아 있음.
  - 이전 GET 정상 응답과 인증 상태 본문 지연의 세션 교체 후 반환을 재현·수정.
    현재 조회/변경 완료 응답 유지·중단된 본문 거절을 단위 검증하고, 이전 보고서의
    저장 억제/현재 저장 경로를 합성 브라우저에서 검수. 전체 컴포넌트 콜백 검수는 남아 있음.
  - 공용 작업 액션·등록 폼의 세션 교체 후 갱신/알림 억제와 요청별 저장 잠금 소유권을 보강.
    실제 임시 HTTP/빌드된 앱에서 관리자 저장 보류→서버 로그아웃→운영자 재로그인→
    새 노트 저장 중 이전 응답 도착의 입력/잠금 유지와 현재 완료·제품 로그아웃을 검수.
    다른 탭·나머지 변경 여정은 남아 있음.
  - 닫힌 비밀번호 변경 화면의 이전 성공이 새 로그인 콜백을 실행하는 문제를
    합성 브라우저에서 재현·수정. 이전 인증 변경 헤더/본문의 새 세션 완료를
    단위 검증하고 사용자 재설정의 닫힌 화면 콜백·현재 비밀번호 완료를 검수.
  - 사용자 수정과 내 비밀번호 변경 입력의 저장 중 잠금·503 후 활성화, 합성 사용자 수정 오류 입력 보존·재시도 저장을 desktop에서 검수.
  - 공용 작업 액션·등록 폼에 탐색/모달 세대 검사를 적용. 늦은 성공·실패, 같은 URL로 이전 탐색 복귀,
    닫고 다시 연 노트의 새 초안 보존과 정상 완료·현재 입력 오류를 desktop에서 검수.
    공용 자산/계획/가져오기/노트 폼의 저장 중 네이티브 입력 잠금과 진행 안내를 적용.
    실제 노트의 대기 중 추가 수정 손실을 수정 전 빌드로 재현하고, 잠금·성공 완료·
    합성 503 후 입력 보존/잠금 해제·수정 후 실제 저장을 desktop에서 검수.
  - 발견 조치의 이전 저장 응답이 같은 상세의 새 초안을 초기화하는 문제를 별도 수정 전 빌드로 재현·수정.
    늦은 성공/실패·버전 충돌·현재 실패 입력 보존과 담당자 목록 오류/같은 검색 재시도를 desktop에서 검수.
    별도 컴포넌트의 나머지 저장 흐름과 전체 폼의 저장 중 동작 검수는 남아 있음.
  - 보고서 다운로드의 진행·중단·한도 초과 대기·수동 재시도를 실제 화면에서 검수.
    HTML/빈 응답/전송 실패 거절은 단위 검증. 대용량 브라우저 자원과 전체 화면 복구 검수는 남아 있음.
- [ ] URL에 탐색 상태 보존, 검색·필터·페이지네이션.
  - 9개 주요 목록과 그래프 북마크 구현. 주요 목록의 새 문서 복원·이전/다음 이력·오류 복구 검수.
    노트 마지막 페이지 삭제 후 위치 보정, 예약 필터·중지 후 위치 유지 검수.
    관찰의 전체 조회·출처 검색·새 탭 복원 검수. 작업·발견 ID의 상세 URL, 닫기·이전/다음 복원·오류 재시도 구현·검수.
    발견의 증거·재검증 목록 펼침·검색·페이지 북마크와 새 탭·이전/다음 복원 검수.
    작업 상세 발견/실행 기록의 독립 검색·페이지·스냅샷 URL, 새 문서·닫기 후 이전 탐색 복원 구현·desktop 검수.
    대화의 펼침·검색·페이지 URL와 새 문서·접기/펼치기·이전/다음 탐색 복원,
    미확인 질문의 동시 복원·중복 없는 재시도·성공 후 최신 위치 복귀를 desktop에서 검수.
    늦은 답변의 검색·접힘·과거 페이지/스냅샷 유지, 이전 화면의 오류 억제,
    상세 닫기 후 저장 확인 시 재시도 정보 정리를 합성 desktop 응답으로 검수.
    변경 이력의 SQL 사유/작성자 검색·펼침/검색/페이지 URL, 새 문서·접기/펼치기·
    이전 탐색 복원과 조치 저장 후 위치 유지·503 오류 구분/조회 복구를 desktop에서 검수.
    개별 원본 펼침/스크롤·나머지 모달 URL, 전체 모바일 회귀는 남아 있음.

## 자산·실행·발견

    계획 생성의 자산 선택은 페이지 간 선택 유지. 발견별 증거·재검증 이력은 SQL 검색·25개 페이지·출처 검증 적용.
    MCP 목록·증거·재검증·이벤트 페이지와 관련 ID SQL 요약은 구현([MCP.md](MCP.md)).
    주요 HTTP 발견 조회·저장 응답의 관련 ID 요약도 구현. 작업 상세의 발견·이벤트도
    최신 25개 요약·전용 SQL 페이지·독립 검색 및 발견 상세 이동을 구현·검수.
    작업 대화도 SQL 검색·25개 페이지·전송 후 최신 복귀와 질문·답변 원자적 저장을 구현.
    전송 ID별 서버 중복 방지와 동일 질문의 화면 재시도도 구현·검수.
    같은 탭의 새 문서·상세 재진입에서 미확인 질문 복원도 구현·검수. 기기 간 복원과 전송 전 초안 보존은 없음.
    보고서는 같은 읽기 스냅샷에서 전체 결과를 스트리밍하며 중단 시 연결 종료를 검증([REPORTS.md](REPORTS.md)).
    내보내기 동시 실행·시간 제한과 거절·완료·중단·시간 초과 지표도 구현·검증.
    서비스 코드의 Store.all 조회를 제거하고 재시작 미완료 작업 100개 배치·자산 SQL 존재 검사·예약 ID 조회를 구현·검증.
    단일 payload·연관 ID 배열/예약 중지 감사 크기와 상세 내부 위치·나머지 모달 URL 상태 보존,
    장시간 부하 검증은 아직 남아 있다.
