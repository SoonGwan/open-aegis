# 명시적 모델 연결 시험 계약

관리자는 현재 검토된 활성 모델 프로필에 고정된 짧은 메시지로 추론 요청을 한 번
보낼 수 있다. 모델 목록 조회와 별도 기능이며 제공자 비용이 발생할 수 있다.
작업·대상·사용자 입력·프롬프트 내용을 보내지 않는다. 프로필·모델 선택·작업 범위·
실행 승인은 변경하지 않는다.

고정 수신처의 chat/completions에 선택 모델, 사용자 메시지 Reply exactly AEGIS_OK.,
max_tokens16, stream=false만 보낸다. HTTP200의 JSON 응답에서 하나의 assistant
답변 AEGIS_OK를 확인한다. 이 프로토콜을 지원하지 않거나 해당 답을 반환하지 않는
모델은 시험 실패로 기록된다. 다른 파라미터나 제공자로 자동 재시도하지 않는다.
시험 성공은 모델 품질·향후 가용성·실제 보안 검증 결과를 보장하지 않는다.

현재 관리자·프로필 버전·검토 지문·실제 인증 설정을 DNS 확인 뒤 요청 직전에 다시
확인한다. 리다이렉트를 따르지 않고 압축·비JSON·중복 키·예상하지 않은 답을 거부한다.
DNS는 최대4초, 전체 요청은8초, 응답은1MiB와 JSON 구조 제한을 적용한다.

시작 영수증과 감사를 먼저 저장하고 최종 결과와 감사를 함께 저장한다. 동일한
사용자·프로필·요청 ID·기준 버전은 이후 편집에도 원래 영수증을 반환한다. 본문이
달라지면409, 다른 시험이 진행 중이면429다. 프로필별 최대200개 기록을25개 SQL
페이지로 조회한다. 서버 재시작이나 소유권 손실로 결과를 확정하지 못한 요청은
unknown으로 보존하며 외부 요청을 다시 보내지 않는다.

영수증에는 당시 프로필·버전·지문·결과 코드·HTTP 상태·응답 SHA256·제공자가 보고한
토큰 카운터를 남긴다. 단가는 요청 시작 때 운영자가 설정한 값을 캡처하며 통화·
입출력 단가·기준일·산정 방식만 저장한다. 유효한 사용량이 있을 때만 추정 금액을
계산한다. 실제 청구와 다를 수 있다. 응답 본문·인증 키·전체 수신처 주소·단가 출처
URL은 저장하지 않는다. 기존 계획·대화 사용량 합계에는 연결 시험을 포함하지 않고
별도 시험 이력에서 사용량과 추정을 표시한다.

- POST /api/model-profiles/{id}/connection-test: 관리자 명시적 시험·동일 요청 재확인
- GET /api/model-profiles/{id}/connection-history: 인증된 시험 이력

화면은 비용 발생 가능성을 표시하고 응답 손실 시 같은 ID·본문으로 결과를 확인한다.
프로필 충돌 시 최신 설정을 명시적으로 검토·채택해야 새 요청을 준비한다. 새 문서의
미확인 요청 복원, 전체 모바일·보조 기술·장시간 운영과 제공자별 어댑터는 별도 범위다.
계약 범위의 설치본606개 테스트, 전체 native1,930개 테스트, 두 저장소 전환·백업
복원, 브라우저 검수와 GitHub 검증6개를 통과했다. SQLite에서는 native 소유권 전용
사례2개를 건너뛴다. 이는 외부 호스팅·전체 ARTEX 기능·v1 출시 완료를 뜻하지 않는다.
