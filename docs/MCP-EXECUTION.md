# 서명된 범위의 MCP GET 실행 서버

별도 `python -m aegis.mcp_execution_server` 서비스에서 검토된 내장 검사 6개를
Streamable HTTP로 실행한다. 일반 플러그인 로더가 아니며 메인 앱의 등록 도구는
여전히 `execution_available=false`다. 메인 작업 승인·Worker·발견 저장과의 연결은
아직 구현하지 않았다. 아래 발급 함수는 신뢰하는 내부 호출자를 위한 기반이다.
HTTP API에서 임의 URL을 받아 권한을 발급하지 않는다.

## 권한과 요청 경계

`aegis.mcp_scope.issue_grant`는 현재 코드 계약을 가진 queued/running 승인 작업의
고정 자산 스냅샷에서만 발급한다. 작업·자산 ID/revision·정확한 URL 범위·검사 ID·
서버 ID·패키지 지문·요청 제한·테스트 계정 환경변수 이름·만료를 HMAC-SHA256으로
서명한다. 기본 유효기간은 60초, 최대 300초다. 승인 시각과 승인된 대기/작업 시간을
넘어서는 권한을 발급하지 않는다. 발급자는 작업 저장소의 승인·현재 상태·취소 여부를
신뢰할 수 있게 읽어야 한다. 현재 함수 자체는 저장소나 사용자 세션을 조회하지 않는다.
이미 발급된 권한의 즉시 원격 취소 API도 아직 없다.

서버는 대상 요청 전에 서명·서버/검사/코드 계약·만료·계정 허용 목록을 확인한다.
요청 수·시간·속도·재시도는 서명된 제한과 서버 상한 중 더 엄격한 값을 적용한다.
재시도 대기 시간은 더 긴 값을 적용한다. 서버 한 인스턴스는 동시에 한 작업만
실행한다. 동일 데이터 디렉터리의 nonce 기록은 프로세스 간 중복 권한 사용을 막지만
서로 다른 작업의 여러 서버 인스턴스에 대한 전역 속도 제한은 제공하지 않는다.

권한은 대상 네트워크 접근 전에 SQLite 트랜잭션으로 소비한다. 같은 승인 작업·자산·
검사·서버의 재발급은 키 교체 후에도 같은 nonce를 사용하며 전체 승인 유효기간 동안
기록을 유지한다. 네트워크 실패 후에도 소비된다. 자동 재시도 또는 재발급으로 같은
검사를 다시 실행하지 않는다. 응답 손실 후 결과 조회 영수증은 아직 제공하지 않는다.
기록 최대 10,000개에 도달하면 새 실행을 거절한다. 기록을 삭제하거나 다른 디렉터리로
바꾸면 재사용 방지 이력이 사라지므로 운영자는 해당 파일과 시계의 무결성을 관리한다.

모든 대상 요청은 기존 Transport의 GET·origin/경로·DNS 전체 IP 검사·연결 IP 고정·
TLS·리다이렉트·응답 크기·중지/시간 제한을 적용한다. 사설 대상은 서명과 서버 양쪽의
명시적 허용이 필요하다. 메타데이터·link-local·multicast 주소는 허용하지 않는다.
관찰한 링크를 자동 요청하지 않는다. GET이라는 사실은 대상 서버의 부작용 부재를
증명하지 않는다. 테스트 계정은 서버가 별도로 허용한 `AEGIS_TEST_*` 변수만 읽는다.
서버 인증/서명 값을 계정으로 전달하거나 알려진 비밀이 결과에 반사되면 거절한다.

## 설정

서버에 다음 값을 별도 환경 설정으로 전달한다. 인증 값과 서명 키는 각각 32바이트
이상으로 서로 다르게 설정하고, 운영 환경의 비밀 저장소에서 관리한다.

| 변수 | 용도 |
|---|---|
| `AEGIS_MCP_SERVER_ID` | 클라이언트 연결 및 서명과 동일한 고정 ID |
| `AEGIS_MCP_BEARER_TOKEN` | MCP HTTP 연결 인증 |
| `AEGIS_MCP_SCOPE_KEY` | 신뢰한 발급자와 서버 사이의 서명 키 |
| `AEGIS_MCP_EXEC_DATA_DIR` | nonce 기록 디렉터리, 기본 `data/mcp-execution` |
| `AEGIS_MCP_EXEC_HOST` / `AEGIS_MCP_EXEC_PORT` | 기본 `127.0.0.1:8791` |
| `AEGIS_MCP_EXEC_LAB` | `1`일 때만 사설 대상 허용; 권한의 허용도 필요 |
| `AEGIS_MCP_TEST_ENVS` | 허용할 테스트 계정 변수 이름, 쉼표로 구분 |
| `AEGIS_MCP_ALLOWED_ORIGINS` | 허용할 정확한 Origin, 기본 모든 Origin 헤더 거절 |

실행은 `python -m aegis.mcp_execution_server`로 한다. 외부 연결에는 HTTPS 프록시와
별도 네트워크 접근 제한이 필요하다. 소유한 loopback 시험에서만 SDK의 명시적
`lab_http=true` 설정을 사용한다. 서버는 `/mcp` POST JSON-RPC, stateless 초기화·
목록·호출과 initialized 알림을 제공한다. SSE 구독·세션 재개·원격 취소는 제공하지 않는다.
HTTP 본문은 64 KiB, 반환 JSON은 512 KiB 제한을 적용한다. 인증·Origin 검사 후
호출을 처리하며 access log를 끈다. 요청 권한이나 인증 원문을 오류 응답에 반환하지 않는다.

## 결과 검증과 남은 통합

`validate_execution_response`는 전체 결과를 먼저 검사한다. 권한 해시·작업/자산/
revision·검사·범위·코드 지문·유효 제한을 대조하고 기존 내장 결과 계약을 적용한다.
트래픽은 범위 내 GET, 허용 IP, 상태/크기/시도 횟수와 본문 해시를 검사한다. 헤더·
원문 응답 본문·인증 값은 결과에 넣지 않는다. 하나라도 잘못되면 전체 결과를 거절한다.
수신자는 검토한 서버 상한과 사설 대상 허용 설정을 명시적으로 전달해야 한다.

코드 지문과 서명은 신뢰한 발급자/서버 사이의 권한·호환성 검사다. 원격 구현의 진실성,
실제 실행 여부, 반환 증거의 진위 또는 OS 격리를 증명하지 않는다. 서버 OS·설정·키
소유자는 신뢰한다. 현재 고정 코드의 협력적 요청 제한이며 임의 플러그인의 CPU/RSS·
파일시스템·egress sandbox는 아니다. 독립 플러그인 계약/격리, 메인 승인·취소·Worker·
원자적 결과/감사 저장, Linux 및 실제 운영 호환 검수가 완료되기 전 v1 완료로 표시하지 않는다.
