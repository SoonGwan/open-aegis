[v1 출시 기준](V1-READINESS.md), [기능 비교](FEATURES.md), 개별 기능 계약에 유지한다.

## 완료한 후보 검수

MCP 클라이언트의 initialize 버전이 예전 값으로 고정된 문제를 실제 소유한
통신으로 수정 전 실패·수정 후 통과를 확인했다. 설치 패키지 버전과 같은 값을
보내도록 수정했으며 기존 MCP·서명 릴리스 검사90개를 네이티브 PostgreSQL과
OpenSSL3 환경에서 통과했다. 검사용 임시 재현은 보존하고 제품 테스트 파일은
변경하지 않았다.

checkout 밖 새 설치 환경에서 잠긴 의존성·pip check·8개 CLI·실제 서버·별도 UI·
인증·관리자 설정·승인 대기 기록·ScopeSentry·기록 대화·감사·정상 종료·임대
해제를 검수했다. 백업/복원·임시 키 서명·변조 거절·사전 점검·데이터 롤백도
통과했다. 대상 요청은0개다.

1.0.0→0.2.0a1→1.0.0 기록 유지보수와 오프라인 백업 복원은 SQLite/PostgreSQL
모두 통과했다. 실제 native 목표·대화·연결·목록 영수증과 선택한 기록/체크포인트를
보존했으며 복원 세션은0개다. 최초 의도한 제공자 POST6개·목록 GET2개·알림
POST2개 외 전환/복원의 추가 요청은0개다. 구버전 유지보수에서는 native 수신처를
제외하고 AI를 끈다. 임의 구버전의 AI 실행 호환성을 보장하지 않는다.

별도의 0.2.0a1→1.0.0→시작 실패→0.2.0a1 복구도 두 저장소에서 통과했다.
설치 HTTP/MCP 버전·변경 실행 예산·이전 계획 승인 거절·사전 점검 백업·실제
DB 쓰기 후 시작 실패/임대 해제·이전 설치본 복구와 UI 재시작·세션 폐기/재로그인·
기존 기록 유지와 이후 쓰기 제거·감사 검증을 확인했다. 이 검사는 같은 스키마2와
같은 의존성 잠금의 소유한 로컬 리허설이며 대상 요청0개다. 임시 키는 제거했다.

종료 후102개 모듈의 고정 해시를 대조했다. 로컬 설정 수정안을
합친 최종 소스04aaf15의 GitHub37412366956도6개 작업 모두 통과했다.
메타데이터와 전체 로그를 앞선 검사와 구분해 보존했다. main native37410825143과
